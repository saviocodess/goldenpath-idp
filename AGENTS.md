# AGENTS

## Objetivo

Manter este repositório pronto para bootstrap em ambiente real sem executar instalações pesadas no ambiente restrito.

## Regras operacionais

- Não executar instalação de dependências neste repositório durante tarefas de scaffold/documentação.
- Priorizar mudanças incrementais com commits semânticos.
- Atualizar documentação junto com código.
- Preservar contratos dos Golden Paths e padrões de engenharia.
