# Standard: CI/CD

## Objective

Ensure predictable, auditable, and quality-gated software delivery for services generated by this platform.

## Mandatory Pull Request Gates

- `lint`
- `typecheck`
- `unit tests`
- `build`
- security checks (when enabled)

No merge to `main` should happen without all mandatory gates passing.

## Branch Protection

- Pull request required for `main`
- At least one technical owner review
- Required status checks
- Prevent stale merges when conflicts are present

## Dependency Installation in CI

- Install dependencies only once per job
- If `yarn.lock` exists: `yarn install --immutable`
- If `yarn.lock` is absent: `yarn install`
- PRs changing dependencies must include lockfile updates in generated services

## Versioning and Release

- Semantic tags: `vMAJOR.MINOR.PATCH`
- Breaking changes must increment `MAJOR`
- Release notes must align with `CHANGELOG.md`

## Deploy and Rollback

- Deploy via GitOps only (PR + merge + Argo CD sync)
- Rollback through PR revert/patch, not ad-hoc manual changes
- Follow runbooks in `docs/en/runbooks`

## Pipeline Metrics

- PR lead time
- pipeline failure rate
- mean time to restore after rollback
